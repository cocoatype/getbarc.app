Barc 25.6 has a number of small bug fixes:

- Code 128 barcodes which have only numbers in them can now display a more-compact format, which may help in scanning them.
- Large PDF 417 barcodes render completely instead of potentially not appearing.
- Adding a new barcode after deleting an existing one works correctly, instead of showing a "need to subscribe" alert.
