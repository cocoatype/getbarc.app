Barc 25.2 adds a new way to import barcodes and fixes several Apple Watch bugs.

### Photo Library Import

Barc can now import images from your photo library and scan them for barcodes, directly within the app. No more opening the Photos app just to add a barcode to Barc!

### Bug Fixes

- Fixed an issue where the Apple Watch complications released in Barc 25.1 never showed up. I apologize strongly for this issue; fixing it took significantly longer than it should have.
- Stopped a common issue on Apple Watch where it would change the currently selected barcode occasionally.
- Further tweaked the dark mode app icon.
