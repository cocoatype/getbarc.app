Barc 25.4 has all kinds of new stuff!

### Custom App Icons

Barc Unleashed subscribers can choose from a set of custom app icons to customize their home screen. This first release of app icons adds Pride Flag, Coffee Shop, and QR Code designs.

### Shortcuts Enhancements

The "create barcode" Shortcuts action has a preference for handling barcodes that were already added to Barc. When detecting a duplicate, Barc can either show an error (the default) or return the original barcode.

A new "delete barcode" action allows you to remove barcodes when you no longer need them.

### Expanded Watch Complications

Barcodes can be added as "corner" complications on watch faces that support them, in addition to the previously-supported "circle" complications.

### New Barcode Format

Store barcodes in the "Interleaved 2 of 5" (ITF) format, often used for product or item IDs.

### Improved Accessibility

Delete barcodes quickly from the main barcode list using actions with VoiceOver or Switch Control.

### Bug Fixes

- Fixed a miscolored icon when deleting a barcode from the barcode list.
- Adding a barcode from inside Barc is much faster when on a slow connection.
- The barcode list correctly refreshes when a new barcode is added.
